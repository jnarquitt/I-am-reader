# I AM

**A novel by J.N.R. Quitt.**

This repository hosts the source for the free online reading site for *I AM* — a work in progress. New chapters are added as they're finished.

**Read it here:** https://jnarquitt.github.io/i-am-reader/

## About this site

This is a lightweight, static reading site: a table of contents, chapter-by-chapter navigation, adjustable text size, and light/dark reading modes, built to be comfortable on a phone or a laptop.

The text here is a work in progress and may be revised, reordered, or expanded before the book is finished.
